100% client-side. The QR code is generated entirely in your browser. Nothing you type is ever sent to a server.

∞
QR codes don't expire. Once generated, the code works forever as long as the underlying link or data stays valid.

How it works

The QR code is created in your browser by the open-source qrcode.js library, loaded from the Cloudflare CDN, using error correction level M, which lets a code stay readable if roughly 15% of it is damaged or covered. URL and text modes encode exactly what you type. Wi-Fi mode encodes your network name, password, and security type in the standard format that phone cameras recognize, so scanning offers to join the network. You can download the code as a PNG.

Frequently asked questions

Do QR codes expire?

A code like this one is static, meaning it holds the information directly, so it never expires. It works as long as the link or information it contains stays valid.

Is it safe to put my Wi-Fi password in a QR code?

The password is stored in the image itself, so anyone who can scan or copy the image can read it. Share it only where you would share the password, and make a guest network for visitors if you can.

What size and contrast work best?

Dark code on a light background with plenty of empty space around it scans most reliably. Print it large enough to scan from a normal distance and test it before printing many copies.

Does the tool track scans?

No. The code goes straight to your destination, and we have no way to see or count scans.
