💨
Fan/convection ovens run hotter for a given dial setting because the fan circulates heat more efficiently. Recipes written for conventional ovens usually need the temperature lowered by about 20°C (25°F), or the fan setting reduced, if you're using convection.
🌡
Gas mark is a UK/Commonwealth scale still printed on many older cookers and used in British recipes. It doesn't map perfectly to exact Fahrenheit/Celsius values — the table shows the standard rounded equivalents.
